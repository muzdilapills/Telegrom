Telegrom - Мессенджер который может стать альтернативой Telegram!

Telegrom это мессенджер сделанный на C# с помощью Avalonia.

КАК УСТАНОВИТЬ Telegrom?

Нажимаете на Code => Download Zip (временно придется так)
Потом закидываете на рабочий стол, заходите в папку => bin => telegrom.exe
Для использования просьба установить dotnet v.10+, иначе не запуститься!
